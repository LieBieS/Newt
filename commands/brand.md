## Description
Complete brand strategy and collateral generation.

## Usage
```bash
# Generate brand strategy package
/brand generate --path ./src --depth full

# Create video storyboard
/brand storyboard --format markdown

# Generate investor presentation
/brand presentation --slides 20

# Create PDF brief
/brand pdf --format executive

# Validate all outputs
/brand validate --quality high
```
